# 💫 About Me:
Hey there! I'm Abhinav — a BTech CSE student at VIT-AP 👨🏻‍💻
Full-stack developer building real products, not just projects. I built 
**AskHimalaya Events** — an event discovery & ticket booking platform for a 
startup — taking their UI designs and product idea and building it out fully: 
front-end, back-end, database, auth, and payments. I've also worked on client 
projects during my internship, shipping full production websites and features 
end to end.

🚀 Currently building with **React, Next.js, Node.js & PostgreSQL**
🧠 Sharpening DSA & Python fundamentals alongside real-world dev work
🎨 Still bring design sensibility into everything I build — clean UI, pastel 
vibes, thoughtful details
